## SYSTEM ARCHITECTURE

XEON-NETCLI ADHERES TO A MODULAR ARCHITECTURE SEPARATING NETWORK TELEMETRY, COMPUTATION ENGINES, AND TERMINAL PRESENTATION:

```
xeon-netcli/
|-- main.py                 # RUNTIME ENTRY POINT WITH WINDOWS UTF-8 INITIALIZATION
|-- requirements.txt        # PYTHON DEPENDENCY MANIFEST
|-- run.bat                 # WINDOWS QUICK-LAUNCH WRAPPER
|-- run.sh                  # LINUX / MACOS EXECUTION SCRIPT
`-- xeon_netcli/
    |-- __init__.py         # PACKAGE METADATA AND VERSION DECLARATION (V1.1.0)
    |-- cli.py              # CASE-INSENSITIVE ARGUMENT PARSER AND DISPATCHER
    |-- menu.py             # INTERACTIVE DASHBOARD, BREADCRUMBS, AND TOOL GUIDES
    |-- commands.py         # COMMAND HANDLERS, THREADPOOL EXECUTORS, AND QUIZZES
    |-- network.py          # OS SOCKETS, ARP/ROUTE PARSERS, AND PSUTIL INTEGRATION
    |-- ui.py               # RICH UI DESIGN SYSTEM, UTF-8 SAFETY, AND ESCAPE LOGIC
    `-- utils.py            # OS ENVIRONMENT DIAGNOSTICS AND SUBPROCESS HELPERS
```

## HOW TO RUN

XEON-NETCLI SUPPORTS TWO OPERATIONAL MODES: INTERACTIVE DASHBOARD MODE AND DIRECT CLI EXECUTION MODE.

### 1. INTERACTIVE DASHBOARD MODE (RECOMMENDED)

LAUNCH XEON-NETCLI WITHOUT ARGUMENTS TO ENTER THE INTERACTIVE MENU:

```bash
python main.py
```

*ON WINDOWS SYSTEMS, YOU CAN ALSO DOUBLE-CLICK `run.bat`.*

**FEATURES OF THE DASHBOARD MODE:**
- **LOCATION BREADCRUMB**: SHOWS YOUR CURRENT NAVIGATION PATH (`LOCATION: MAIN MENU >> CATEGORY >> TOOL`).
- **MODULE DOCUMENTATION**: EVERY TOOL FEATURES AN OVERVIEW, TECHNICAL PURPOSE, AND USAGE INSTRUCTIONS.
- **SMART DEFAULTS**: PRESS `ENTER` TO ACCEPT PRE-CONFIGURED DEFAULTS (E.G. TARGET: `google.com`, CIDR: `192.168.1.0/24`).
- **NAVIGATION LOOP**: PRESS `ENTER` TO RETURN TO THE MAIN MENU, `'R'` TO RE-RUN THE CURRENT TOOL, OR `'0'` TO TERMINATE.

---

### 2. DIRECT CLI EXECUTION MODE

EXECUTE ANY UTILITY DIRECTLY AS A ONE-LINER FROM YOUR TERMINAL (SUPPORTS BOTH LOWERCASE AND UPPERCASE COMMANDS):

```bash
# SYSTEM INFORMATION
python main.py info

# SUBNET ANALYSIS
python main.py subnet 10.0.0.0/22

# MULTI-PORT FAST SCAN
python main.py scan 127.0.0.1 -p 80 443 3306 8080

# END-TO-END HEALTH DIAGNOSTIC
python main.py diagnose google.com
```

## MODULE REFERENCE & USAGE EXAMPLES

### CATEGORY 1: NETWORK IDENTITY & HARDWARE

#### 11 - SYSTEM & NETWORK OVERVIEW (`info`)
RETRIEVES LOCAL HOSTNAME, OPERATING SYSTEM PLATFORM, REAL-TIME CPU/RAM UTILIZATION, PRIMARY LAN IP, DEFAULT GATEWAY, AND PUBLIC WAN GEOLOCATION.
```bash
python main.py info
```

#### 12 - NETWORK ADAPTERS & STATE (`interface` / `if`)
LISTS ALL PHYSICAL, VIRTUAL, WIRELESS, AND LOOPBACK ADAPTERS WITH ACTIVE OPERATIONAL STATES (`● UP` / `○ DOWN`), IPV4, IPV6, PHYSICAL MAC ADDRESSES, MTU SIZES, AND LINK SPEEDS.
```bash
python main.py interface
```

#### 13 - PUBLIC WAN IP & GEOIP (`publicip` / `wan`)
QUERIES REMOTE GEOLOCATION SERVICES TO IDENTIFY YOUR EXTERNAL IP, INTERNET SERVICE PROVIDER (ISP), AUTONOMOUS SYSTEM (AS) NUMBER, CITY, AND COUNTRY.
```bash
python main.py publicip
```

#### 14 - ACTIVE ROUTING TABLE (`route`)
PARSES AND STRUCTURES THE ACTIVE KERNEL IPV4 ROUTING TABLE, DISPLAYING NETWORK DESTINATIONS, NETMASKS, NEXT-HOP GATEWAYS, INTERFACES, AND METRIC PRIORITIES.
```bash
python main.py route
```

#### 15 - ARP CACHE INSPECTION (`arp`)
INSPECTS LOCAL ADDRESS RESOLUTION PROTOCOL (ARP) MAPPINGS BETWEEN IPV4 ADDRESSES AND PHYSICAL HARDWARE MAC ADDRESSES DISCOVERED ON THE LOCAL SUBNET.
```bash
python main.py arp
```

#### 16 - WIRELESS (WI-FI) TELEMETRY (`wifi`)
DISPLAYS CURRENT 802.11 WI-FI INTERFACE STATUS, INCLUDING SSID, BSSID, RADIO STANDARD, AND A VISUAL SIGNAL STRENGTH METER (`[████████░░] 80%`).
```bash
python main.py wifi
```

---

### CATEGORY 2: IP & SUBNET CALCULATORS

#### 21 - IP ADDRESS DEEP ANALYZER (`ip <address>`)
ANALYZES AN IP ADDRESS: RFC 1918 PRIVATE/PUBLIC STATUS, LOOPBACK/MULTICAST ATTRIBUTES, HEXADECIMAL/INTEGER VALUES, ADDRESS CLASS (A-E), AND 32-BIT DOTTED BINARY NOTATION.
```bash
python main.py ip 192.168.1.10
```

#### 22 - SUBNET CALCULATOR (`subnet <network/cidr>`)
COMPUTES NETWORK ADDRESS, BROADCAST ADDRESS, SUBNET MASK, WILDCARD MASK, TOTAL IP COUNT, USABLE HOST CAPACITY, USABLE IP RANGE, AND BINARY NETMASK.
```bash
python main.py subnet 172.16.0.0/20
```

#### 23 - VLSM SUBNETTING CALCULATOR (`vlsm <base_network> <hosts...>`)
VARIABLE LENGTH SUBNET MASKING ALLOCATION PLANNER. INPUT BASE CIDR AND SPACE-SEPARATED HOST REQUIREMENTS TO RECEIVE AN OPTIMAL ZERO-WASTE SUBNETTING SCHEDULE.
```bash
python main.py vlsm 192.168.1.0/24 60 30 10 2
```

#### 24 - CIDR CHEAT SHEET (`cidr`)
DISPLAYS A COMPLETE REFERENCE SHEET COVERING ALL 33 IPV4 PREFIXES (/0 THROUGH /32), INCLUDING SUBNET MASKS, WILDCARDS, AND USABLE HOST LIMITS.
```bash
python main.py cidr
```

### CATEGORY 3: DIAGNOSTICS & CONNECTIVITY

#### 31 - FULL NETWORK HEALTH CHECK (`diagnose` / `diag`)
RUNS A 4-LAYER INTEGRATED DIAGNOSTIC PIPELINE:
1. LOCAL ADAPTER OPERATIONAL STATE
2. DEFAULT GATEWAY REACHABILITY
3. SYSTEM DNS RESOLUTION
4. REMOTE ICMP INTERNET CONNECTIVITY
```bash
python main.py diagnose google.com
```

#### 32 - ICMP PING ANALYZER (`ping <host> [-c count]`)
TRANSMITS ICMP ECHO REQUEST PACKETS, MEASURING MIN/AVG/MAX ROUND-TRIP TIME (RTT), DETECTING PACKET LOSS PERCENTAGES, AND REPORTING DESTINATION HEALTH.
```bash
python main.py ping 8.8.8.8 -c 4
```

#### 33 - TRACEROUTE PATH INSPECTOR (`trace` / `traceroute <host> [-m max_hops]`)
MAPS THE HOP-BY-HOP NETWORK PATH TRAVERSED BY PACKETS ACROSS ROUTERS TO REACH A REMOTE DESTINATION.
```bash
python main.py trace 1.1.1.1 -m 15
```

#### 34 - DNS RESOLVER (`dns <host> [-t type]`)
PERFORMS DNS QUERIES RETURNING RESOLVED IPV4 (A) AND IPV6 (AAAA) ADDRESSES FOR A SPECIFIED DOMAIN NAME.
```bash
python main.py dns cloudflare.com
```

#### 35 - HTTP / HTTPS DIAGNOSTICS (`http <url>`)
PERFORMS AN APPLICATION-LAYER HTTP/HTTPS REQUEST TO INSPECT STATUS CODES, LATENCY, CONTENT HEADERS, PROTOCOL VERSIONS, AND SERVER DAEMONS.
```bash
python main.py http https://google.com
```

### CATEGORY 4: PORTS & ACTIVE TRAFFIC

#### 41 - SINGLE TCP PORT CHECK (`port <host> <port>`)
ATTEMPTS A TCP THREE-WAY HANDSHAKE WITH A SPECIFIED PORT ON A TARGET HOST TO DETERMINE IF THE SERVICE IS OPEN, CLOSED, OR FILTERED BY A FIREWALL.
```bash
python main.py port 192.168.1.1 80
```

#### 42 - MULTI-PORT FAST SCANNER (`scan` / `portscan <host> [-p ports...]`)
CONCURRENT MULTI-THREADED SCANNER AUDITING COMMON DAEMONS (SSH, HTTP, HTTPS, MYSQL, RDP, SMB, DNS, ETC.) OR USER-DEFINED PORT LISTS WITH REAL-TIME PROGRESS BARS.
```bash
# SCAN TOP 25 COMMON PORTS:
python main.py scan 127.0.0.1

# SCAN SPECIFIC CUSTOM PORTS:
python main.py scan 192.168.1.1 -p 22 80 443 3389 8080
```

#### 43 - ACTIVE TCP SOCKETS & PIDS (`connections` / `conn`)
INSPECTS LOCAL OPERATING SYSTEM SOCKETS, MAPPING LOCAL AND REMOTE ADDRESSES, CONNECTION STATES (`ESTABLISHED`, `LISTEN`, `TIME_WAIT`), AND PROCESS NAMES (PIDS).
```bash
python main.py connections
```

#### 44 - LIVE BANDWIDTH MONITOR (`monitor [-i interval]`)
REAL-TIME NETWORK THROUGHPUT MONITOR TRACKING DOWNLOAD (RX) AND UPLOAD (TX) TRANSFER SPEEDS WITH DYNAMIC UNITS (B/S, KB/S, MB/S). PRESS `CTRL+C` TO STOP.
```bash
python main.py monitor -i 1.0
```

### CATEGORY 5: STUDENT STUDY LAB & QUIZZES

#### 51 - PROTOCOL & PORT DIRECTORY (`protocol <port|service>`)
SEARCHABLE REFERENCE OF IANA-ASSIGNED PORT NUMBERS, TRANSPORT PROTOCOLS, AND SERVICE DEFINITIONS.
```bash
python main.py protocol 443
python main.py protocol ssh
```

#### 52 - OSI 7-LAYER ARCHITECTURE (`learn OSI`)
EDUCATIONAL BREAKDOWN OF ALL SEVEN LAYERS OF THE OSI MODEL, DETAILING FUNCTIONS, PROTOCOL DATA UNITS (PDUS: BITS, FRAMES, PACKETS, SEGMENTS, DATA), AND PROTOCOLS.
```bash
python main.py learn OSI
```

#### 53 - TCP 3-WAY HANDSHAKE (`learn TCP`)
STEP-BY-STEP VISUALIZATION OF TRANSMISSION CONTROL PROTOCOL (TCP) CONNECTION ESTABLISHMENT USING `SYN`, `SYN-ACK`, AND `ACK` FLAGS.
```bash
python main.py learn TCP
```

#### 54 - IPV4 ADDRESS CLASSES (`learn CLASSES`)
TECHNICAL OVERVIEW OF CLASSFUL IPV4 NETWORKING (CLASSES A, B, C, D, E), DEFAULT NETMASKS, AND RFC 1918 PRIVATE RESERVED BLOCKS.
```bash
python main.py learn CLASSES
```

#### 55 - INTERACTIVE SUBNETTING QUIZ (`quiz`)
PRACTICE ASSESSMENT GENERATING 5 MULTIPLE-CHOICE QUESTIONS TESTING SUBNETTING, CIDR PREFIXES, USABLE HOSTS, OSI LAYERS, AND PORT NUMBERS WITH INSTANT EXPLANATIONS AND SCORING.
```bash
python main.py quiz
```
